# Preproute Test Management Application

Frontend Developer Assessment Submission built using React, TypeScript, Vite, and React Router.

## Live Demo

**Vercel Deployment:** https://preproute-test-management-app-ecru.vercel.app/

## GitHub Repository

**Repository Link:** https://github.com/Mahak-agrawal05/preproute-test-management-app

## Features

* User Authentication (Login & Validation)
* Protected Routes
* Dashboard for Viewing Tests
* Create Test Form with Validation
* Edit Existing Tests
* Delete Tests
* Question Management (Add, Edit, Delete MCQs)
* Preview & Publish Workflow
* API Integration using Axios
* Fully Responsive Design (Mobile, Tablet, Desktop)

## Tech Stack

* React
* TypeScript
* Vite
* React Router DOM
* Axios
* React Hook Form
* CSS

## Installation & Setup

```bash
git clone https://github.com/Mahak-agrawal05/preproute-test-management-app.git

cd preproute-test-management-app

npm install

npm run dev
```

Application will run at:

```bash
http://localhost:5173
```

## API Integration Note

API integration has been implemented as per the provided documentation and requirements.

During final verification, browser-based requests to the staging backend encountered CORS-related restrictions in both local and deployed environments. However, the API endpoints were successfully tested separately during development.

The frontend implementation, validation, routing, UI workflows, and API integration logic have been completed and are ready to work with the configured backend environment.
